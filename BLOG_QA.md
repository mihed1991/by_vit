## Функциональные проверки

- `npm run check`: серверные проверки проекта.
- `npm run check:blog`: SSR, метаданные, черновики/архив, редактор, сохранение,
  безопасный предпросмотр, товары/корзина, рубрики, пагинация и пустые состояния.
- `npm run check:blog-export`: реальная сборка публичного экспорта, изображения,
  sitemap и отсутствие черновиков/архива в артефактах.
- `npm run check:e2e`: десктопные и мобильные сценарии магазина.
- `npm run check:static`: вложенные URL GitHub Pages, ресурсы и отсутствие API-вызовов.
- `npm run check:goals`, `npm run check:brands`: существующие разделы.
- `git diff --check` и синтаксические проверки новых JS/серверного кода.

Проверки браузера выполнялись в Chromium; реальный Safari/iPhone не проверялся.
Автоматически проверены ширины 320, 390, 760, 820, 1100, 1440px без горизонтального переполнения.
Тестовые базы и публикации изолированы во временных каталогах; рабочая база не изменена.
